# Event Tickets with Ticket Scanner

Sell tickets on your own site: seating plans, PDF tickets with QR codes, a built-in POS for door sales (box office), online payments (Stripe, PayPal, Mollie) and a mobile ticket scanner — no per-ticket service fees.

**[Download the free version](https://vollstart.com/free-event-ticket-plugin)** · **[Premium](https://vollstart.com/event-tickets-with-ticket-scanner/)** · **[Docs](https://vollstart.com/event-tickets-with-ticket-scanner/docs)** · **[Live demo](https://vollstart.com/test/wordpress-testing/)**

## What the free version includes

- Ticket generation with QR codes (up to 50 tickets, 5 ticket lists)
- PDF ticket download
- Built-in mobile ticket scanner (PWA, iOS/Android, hardware scanners)
- Interactive seating plan designer (1 plan, up to 20 seats) + seat selection
- Multi-entry and family tickets, day chooser for date-based events
- Direct sales without WooCommerce: own shop pages, box office POS with QR payment
- Attendee portal / event info app
- Webhooks for third-party integrations

[Premium](https://vollstart.com/event-tickets-with-ticket-scanner/) adds PDF attachments, team scanner access via auth tokens, ICS calendar invites, CVV security check, brute-force IP blocking, unlimited tickets and more.

## Installation

1. Download the latest ZIP from [releases](../../releases) (or [vollstart.com](https://vollstart.com/free-event-ticket-plugin))
2. In WordPress: **Plugins → Add New → Upload Plugin** → choose the ZIP
3. Activate, then find **Event Tickets** in your admin menu
